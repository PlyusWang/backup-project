## 状态与优先级约定

- **已修复**：有对应提交及 RED/GREEN 或完整门禁证据；不再作为未完成任务重复安排。
- **已知限制 / 待加固**：存在明确的条件和威胁模型，但未证明普通工作负载会触发破坏；保留为技术债。
- **待复现缺陷**：先写最小、确定性测试；一旦证实普通使用下可造成误删、误覆盖或错误成功报告，升级为当前 P0/P1 缺陷。
- **未来功能**：新能力、跨平台或界面扩展；不得与安全回归混成同一修复 PR。

优先级是**相对于该任务成立的前提**评估的，不等于立即实施授权。P1 应优先评估，P2 可在后续安全专项处理。不要为了清空 backlog 在已通过的 PR 中无限扩大修改范围。
