# 已知问题与限制

## 已实现

- 本地/云端快速、定时、实时备份。
- 完整/增量、依赖链恢复。
- BPSEC1/BPSEC2、前台 SSH。
- 上传/下载断点续传。
- BPSNAP1 崩溃一致性、临时归属。
- 云端定时/实时版本保留与依赖保护。
- 长期 BPSOWN1 归属账本。
- 无人值守密码命令超时/回收。
- 进程内有界重试（最多 3 次，1s/2s 退避）。

## 限制

1. 后台定时/实时云端 SSH 隧道未支持，只支持直连 BPSEC1/BPSEC2。
2. 系统密钥环没有真实 E2E；0600 明文/密码命令仍可用。
3. 真实 ECS 最新版未联调。
4. Windows 原生最新版未构建验收。
5. 重试不是持久队列；进程退出后不保留待重试任务。
6. 重试专项主要使用 full 快照，未构造重试后的增量父链。
7. 云端 retention 的归属记录不会主动压缩已删除 ID；不影响安全性，但账本会增长。
8. 35 张截图包含重复画面，不是 35 个独立场景。
