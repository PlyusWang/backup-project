# 会话凭据与自动任务验收记录

本记录对应 P1-02、P1-03 和云端自动任务入口。附件中加密输入、定时任务回退及连接失败的历史现象映射见本轮隔离工作区的 `input-evidence/evidence-summary.md`。历史截图不作为当前版本已经通过的证据。

## 实现

- 定时、实时页面提供归档密码与确认密码输入。两项均采用密码回显；两次不一致时拒绝解锁。保存解锁后清空输入，离开页面或销毁页面也清空输入。
- 配置保留会话引用，秘密保存在进程内受互斥锁保护的值容器。归档引用位于 `/@backup-project-session/` 命名空间，保留引用在读取时只查内存，绝不回退同名文件。进程结束后必须重新输入密码。
- 原来的高级口令文件方式保留，其普通文件、所有者与权限检查保持生效。切换为不加密或高级文件并成功保存后清除不用的会话归档口令。
- 定时与实时完整备份使用共享 managed full 入口，使有效完整快照具备后续增量所需的基线副文件。定时增量传递真实加密方式与口令；加密格式、认证和链恢复继续由共享核心负责。
- 云端自动任务可以选择备份管理中已登录的连接。账号密码、身份验证参数和有效拨号端点只保存在当前进程内，任务配置只存会话引用与稳定仓库标识。重新启动需要重新登录。
- SSH 会话使用当前环回转发端口拨号，仓库归属使用逻辑目标标识；自动分配的本地端口改变不会悄悄更换仓库归属。
- 退出登录、端点、身份或连接配置变更，以及 SSH 通道不可用时清除共享连接。异步登录记录配置代次；配置变化后的旧登录结果不能再次发布共享凭据。
- 云端链恢复把用户输入的归档密码传入共享恢复选项；对话框取消、Esc 和提交后清空输入。归档密码与登录密码分别传递。

## 边界

本实现没有宣称使用系统密钥库，也没有把密码哈希当作解密密钥。普通配置、历史记录、命令参数和截图不保存口令。内存容器在替换、清除和析构时尽力擦除自身副本；Qt、标准库及工作任务可能存在短期值副本，因此这不是内存加密或锁页保密承诺。已经取得值副本的在途任务可以完成，清除会话阻止后续任务取得凭据。

高级凭据文件属于用户明确选择的兼容方式；普通 GUI 操作不会自动创建明文口令文件。测试服务器仅使用本轮生成的临时状态、随机密钥及运行期随机口令，清理只作用于测试自行创建的进程与目录。
