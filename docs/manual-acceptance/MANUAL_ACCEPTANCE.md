# 人工验收指南

> 本指南对应历史人工验收包（基线 `a6dc901`），不用于替代 `v0.2.1-rc4` 的 Release
> 验收说明和附件。

> 所有测试使用专用目录，不要用真实重要备份。云端保留测试会删除测试快照。

## 1. 确认版本

```bash
cat VERSION.txt
sha256sum ubuntu/bin/backup-gui-modern
```

与交付报告中的 HEAD/SHA 对照。

## 2. 启动 GUI

```bash
cd ubuntu
./bin/backup-gui-modern
```

预期：显示“首页/快速备份/定时备份/实时备份/备份管理”。

## 3. 本地完整备份

1. 创建测试源目录，放入普通文件、中文文件和子目录。
2. 备份管理 → 本地仓库，选择测试仓库目录。
3. 快速备份选择该源，执行完整备份。
4. 记录快照 ID 和时间。

## 4. 增量备份

修改一个文件后再执行增量；确认父快照/代数显示正确。

## 5. 恢复

在备份管理选择最新快照 → 恢复 → 选择新目录；逐字节比较源与恢复目录。

## 6. 定时备份

定时备份 → 选择源和本地/云端目标 → 设置较短周期（如 1 分钟）→ 启用；观察历史和下次运行时间。

## 7. 实时备份

实时备份 → 选择源 → 启用 → 修改文件；观察新快照和运行状态。

## 8. 隔离云端服务器

```bash
cd ubuntu
./scripts/run-test-server.sh
```

默认 `127.0.0.1:18766`、数据目录 `ubuntu/test-server-data`。  
脚本打印实际地址/端口/数据目录/指纹；账号在本机 GUI 注册，脚本不预置密码。  
不要影响已有 `test-server-data` 或正式 ECS；需要独立目录时传入路径：`./scripts/run-test-server.sh /tmp/my-test-server`。

用打印的命令查询指纹，例如：

```bash
./bin/backup-server-keygen --show --key-file /tmp/my-test-server/transport.key
```

在 GUI 中使用 `sha256:<指纹>` 进行 BPSEC1 验证。

## 9. 上传/下载/恢复

备份管理 → 云端仓库 → 登录测试账号 → 上传原始归档/执行云端备份 → 下载/恢复。

## 10. 错误与断网

- 故意输入错误密码，确认明确失败且不重试无限次。
- 停止测试服务器后再触发，确认失败提示；重启后再次触发成功。

## 11. 版本保留

设置保留数量，创建多个测试快照；确认只删除属于该任务且不破坏依赖链的旧快照。
**禁止在正式仓库测试删除。**

## 12. 记录问题

记录：操作步骤、预期、实际、截图/日志、复现频率。
