# Backup Project UML V4

- `index.html`：图纸目录，包含 PDF、SVG 和图源链接。
- `sources/drawio/`：12 份可在 diagrams.net 中编辑的图源。
- `sources/puml/`：5 份完整顺序图的 PlantUML 源码。
- `sources/report_puml/`：2 份报告顺序图的 PlantUML 源码。
- `figures/a4pdf/`：17 张主图的 A4 PDF，长顺序图按页连续阅读。
- `figures/svg/`：17 张主图的 SVG 矢量图。
- `figures/report/a4pdf/`、`figures/report/svg/`：2 张报告顺序图，各按操作阶段分为两页，控制框在所在页完整闭合。
- `figure_manifest.csv`：主图、图源和导出文件索引。
- `report_figure_map.csv`：报告插图与本目录图纸、图源的对应关系。
